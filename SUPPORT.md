# Support

For installation problems, bug reports, and feature requests, use
https://github.com/suwonleee/llmwiki/issues.

Include the llmwiki version, harness and version, operating system, Bun version, the command that
failed, and sanitized error output. Do not post transcripts, credentials, private repository
content, or the contents of your local llmwiki state directory.

For a security vulnerability, use GitHub's private vulnerability reporting flow instead of a
public issue: https://github.com/suwonleee/llmwiki/security/advisories/new.

Support is community-maintained and provided on a best-effort basis.
